# 格致 0.0.2：学习工作室

2026-10-02。按用户授权实现五个功能，沿用现有 Electron、题库、数字人、日历和导出模块。历史记忆与附件作为背景资料，未把附件内容当成新的执行指令。

## 使用入口

打开资料库后，点击左侧立方体图标“学习工作室”，或首页的学习工作室入口。题库卡片上的“记录自信度练习”直接打开对应题目；原关系图谱的“学习证据地图”按钮打开证据视图。五个功能在工作室顶部切换。

| 功能 | 已实现的行为 |
| --- | --- |
| 自信度记录 | 揭晓前必选猜测、大概或确定；记录原始作答、来源、时间、提示和参考答案预览；选择题与可解析的单个数值答案自动核验 |
| 错误侦探 | 查找推导中最早出错的一步，选择修正方案，写下原因；错误定位和修正都正确才算通过；有数学、物理、概率、化学四个原创案例 |
| 学习证据地图 | 按知识点显示疑似误区、需要练习、等待复测等状态及判断依据；支持搜索、筛选、缩放、平移、节点拖动、键盘选择、关联笔记和针对性练习 |
| 迁移挑战 | 函数、受力、独立事件三条路径，每条三关；由基础应用到条件变化再到生活情境；主进程也检查前一关是否通过 |
| 概念实验台 | 函数图像、受力与运动、概率抽样三个交互实验；调参后固定本轮条件，先写预测、自信度和依据，再验证；保存观察与解释 |

数字人可以朗读解析和学习建议，并通过原有 AI 通道回应追问。AI 追问需要用户已有的 AI 配置，朗读沿用现有云端或系统语音能力。学习记录本身的保存、客观核验和实验模型不依赖云端 AI。

## 数据与证据规则

- 内置目录为 16 道原创练习：3 道普通练习、4 道错误侦探、9 道迁移挑战。均标明“格致原创学习练习 · 非考试真题”；没有将原创练习包装成考试真题或新增电子书。
- 工作室接入当前资料库现有题库，默认载入最近 500 道。更早的题目可从题库卡片直接进入。未填写来源的题目明确标记为来源未填写。
- 仅明确的单选答案和可解析的数值 / 分数答案自动核验。多选答案列表、证明、文字答案和无法解析的答案进入自评；自评不会变成自动核验通过。
- 从当前题库页面看过答案再进入练习，会记录参考帮助。使用提示或参考帮助的正确作答不计入“独立通过”。此记录不检测用户在软件外看过哪些资料。
- 文字推理、纠错原因和观察均保存，但没有实现文字推理的自动语义评分。答对选项不等于完整论证已核验，反馈中会说明这一点。
- “疑似误区”表示最近一次客观核验答错且自信度为确定；“近期独立通过”仅说明近期有一次无提示、无参考帮助的客观通过，不宣称全面掌握。
- 最近一次独立通过超过 24 小时，会建议复测。“延迟复测证据”要求不同题目的独立通过相隔至少 24 小时。同题重复答对不构成延迟复测证据。
- 迁移挑战允许使用提示解锁下一关，但证据地图中的独立迁移等级只采用无提示的通过记录。
- 一个题库题目的作答归入其第一个知识点标签，其他标签可产生共现关联，不把一题通过自动扩展为所有标签都通过。
- 实线箭头为明确设计的教学前置关系，虚线为教学关联或题目标签共现。文件链接仍由原笔记关系图谱显示。
- 支持为知识点安排明天的复测待办。重复安排会复用现有未完成待办，保留日历中的固定课程。

记录存储于软件本机用户数据目录的 `learning.db`，按资料库真实路径分开。新数据库独立于既有 `bank.db`、`calendar.db` 和笔记文件。每次作答保留题目、答案和解析快照，删除或修改题库原题不会抹掉过去的学习依据。

地图一次展示最多 80 个筛选后的节点；关联笔记查询上限为原搜索模块的 1500 个节点。每个知识点显示最近 8 条依据，工作室导出最近 120 条记录并明确说明数量。累计统计使用全部存储记录，未因显示上限删除历史。

## 实验模型

函数模型为 `y = a(x-h)²+k`，支持开口、平移及 `a=0` 的常函数退化；图像超过显示范围会裁切。受力实验是从静止开始的水平恒力简化模型，取 `g=9.8 m/s²`，静、滑动摩擦系数相同，忽略空气阻力；拉力不足以克服静摩擦时加速度为零。默认参数下加速度为 `4.02 m/s²`，3 秒位移为 `18.09 m`。

概率实验统计每组 `n` 次独立试验中至少成功一次的组数，理论概率为 `1-(1-p)^n`，每轮最多抽样 10000 组。使用有种子的伪随机抽样便于复现；抽样频率有波动。主进程与界面共用模型函数，参数都有边界检查。系统启用减少动态效果时，受力实验直接显示最终状态。

## 验证与发布

启动报错来自数值转换函数内的重复变量声明，已修复。安装包构建流程增加所有主进程 CJS 模块和共享模型 MJS 的 `node --check`，语法失败时停止构建。

```powershell
node --test apps/desktop/learning.test.mjs
node apps/desktop/node_modules/typescript/bin/tsc --noEmit -p apps/desktop/tsconfig.json
npm --prefix apps/desktop run build:renderer
node apps/desktop/verify-learning.mjs
node apps/desktop/verify-workbench.mjs
node scripts/build-installer.mjs
$env:GEZHI_TEST_EXE = Join-Path (Get-Location) 'dist/installer/win-unpacked/格致.exe'
node apps/desktop/verify-learning.mjs
```

验证均使用隔离资料库和用户数据目录，不写入真实学习资料。AI 回复和云端 TTS 在交互验证中使用测试替身；口型、音频播放、preload、SQLite、实际实验公式和文档导出走真实软件实现。这些检查不代表已验证外部账号、真实 AI 回复质量或实际云端语音服务可用性。

单元测试共 19 项，覆盖自信度约束、重复提交、来源快照、参考帮助、错误定位与修正、逐关解锁、保守核验、跨库隔离、延迟证据和实验边界。学习工作室集成检查共 26 项，另有 33 项既有界面回归检查，包含 1500 节点压力图谱。主动停止朗读会清理播放状态，取消后的异步回调不会显示播放器错误或恢复旧音频。最终检查结果和安装包摘要见 `产出/learning-studio/release-manifest.json`；集成报告和截图见同目录的 `verification.json` 与 `packaged/verification.json`。

本次安装包为 `dist/installer/格致-0.0.2-安装包.exe`。升级使用现有用户数据；原 0.0.1 安装包保留。未提交或推送 Git，也未安装或覆盖用户正在使用的软件。
