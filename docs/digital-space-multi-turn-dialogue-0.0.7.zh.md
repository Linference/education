# 数字空间多轮学习对话 · 0.0.7

2026 年 10 月 7 日。延续 0.0.6 的资料引用与学习闭环，增加可以持续回应的角色对话。

## 使用方式

1. 打开自己的资料，在学习工作室选择章节或页段。
2. 进入角色空间，输入主题与至少 10 字的开场讲解。
3. 点击“让角色追问”，回应问题后点击“回应并继续”，也可以按 Ctrl+Enter。
4. 选择符合角色的追问方式，查看逐字匹配的原文引用。
5. 点击“生成整段对话反馈”，逐维查看自己的原话、判断与下一步建议。

每段最多 12 轮，学习者讲解与补充合计最多 12000 字。每轮补充最多 5000 字。仍支持直接提交一段讲解生成六维反馈。

| 空间 | 可选追问方式 |
| --- | --- |
| 同学陪练 | 一起理清思路、换生活例子 |
| 教师指导 | 检查推理、检查适用条件 |
| 学生听众 | 简单解释、举例教学 |
| 考官追问 | 边界与反例、换情境 |
| 研究伙伴 | 可检验预测、改变假设 |

## 原文与评分依据

会话开始时固定资料快照。后续打开其他文件不会悄悄更换本段引用；可以回到本轮资料，或新开一轮使用新资料。

模型给出的 `referenceEvidence` 必须逐字出现在快照文本中，否则删除引用并显示尚无匹配依据。匹配后可以在资料栏高亮定位。逐字匹配核验的是引用出处，不保证模型判断正确。

评分主进程从保存的会话中重新提取学习者发言，覆盖渲染端传入的主题、角色、讲解及参考。角色回应仅作为上下文，不能作为学习者自己的证据。没有学习者原话的维度保留未评分状态。AI 分数不增加独立通过数量。

报告保存生成时的完整对话与引用快照，后续对话不能改写此前报告。Markdown 导出附整段学习者讲解、来源、对话快照与六维反馈。

## 保存、恢复与重试

`companions.db` 增加 `room_sessions` 与 `room_drafts` 表，不删除已有报告。对话按资料库保存，草稿按资料库、角色和资料快照区分。每个角色保留最近 30 个来源的草稿，会话历史展示最近 20 段。

草稿在输入后自动保存；界面显示保存状态并提供失败重试。开场讲解、未发送回答、改进重点和会话引用在程序重启后恢复，空白与换行保留。

请求使用独立提交标识。学习者回答先落盘，再等待模型；额度失败、停止或重启中断后，保留回答并重试同一标识。已完成请求再次提交不会重复追加，也不会再调用模型。修改同一标识的内容会被拒绝。中断请求恢复为可重试状态。

## 界面

角色卡片展示各自任务。空间包含资料、角色状态与连续对话；聊天气泡按发言者区分，显示追问轮数。思考、倾听和朗读状态跟随实际请求、录音及播放状态。新增动画尊重系统减少动态效果，支持深浅主题与紧凑窗口。
