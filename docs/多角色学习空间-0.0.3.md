# 格致 0.0.3：多角色空间与交付说明

2026-10-06。按用户请求增加随包 DeepSeek Harness 安装程序、首次启动登录引导、五个数字人空间、六维讲解反馈，并继续修复题库导入和 Markdown 转 PDF。

## 安装和登录

安装包包含 `resources/dsh/dsh-installer.exe`，保留本机已有的 DeepSeek Harness 0.2.0-rc.2 完整安装程序的原始字节与许可。摘要位于 `vendor/dsh/manifest.json`。

首次运行格致显示连接引导。未安装时可以启动随包安装向导；安装后打开官方 DeepSeek Harness 窗口完成登录或配置模型，再返回格致。格致不代理收集账号密码。离线入口保留本机笔记和题库功能。

运行时版本检查不等于账号登录验证；实际模型请求的认证、额度和服务错误会如实显示。检测到余额不足时不生成或保存评分，不使用演示评分冒充服务返回。

角色素材采用内置 imagegen 生成，最终项目资产为 `apps/desktop/renderer/src/assets/companion-roles-v1.png`。这是一张五列透明图集，软件按列显示，原图不经过裁切修改。新角色头像采用轻微呼吸和朗读状态动画；尚未制作各角色专用的多表情口型图集。原有小格的六表情和口型功能仍保留。

生成提示：五个不同的高品质 3D 编辑插画半身数字人，依次为穿淡紫连帽衫的亚洲少年同学、戴眼镜穿深蓝开衫的亚洲女教师、穿青绿色校服的亚洲少女学生、穿深灰外套的亚洲男考官、银发蓝灰实验服研究伙伴。等宽水平排列、相同画面尺度、透明背景，统一柔和光照和石墨灰/淡紫/青绿配色；不含文字、边框或标志。工具为内置 imagegen。

## 六维反馈与数据边界

六维为概念准确性、条件完整性、推理连贯性、表达清晰度、举例能力、迁移应用。量规 0–4；没有可观察证据时返回 `null`，显示“未展示”，不视为零分。

每维包含实际讲解原话、判断依据和下一步建议。主进程校验六维标识、分数范围及引用是否逐字存在于讲解；证据无效的分数不绘入图。无完整返回、超时、取消或余额不足时不保存评分。文字摘录核验不等于语义正确性校准，量规尚未经教师实证验证。

参考文本最多 12000 字；主题最多 200 字；讲解 10–12000 字。此路径要求 AI 不调用工具，观察到工具请求时停止评估。它不是操作系统级的无工具隔离保证。

成功记录保存在用户数据目录的 `companions.db`，按资料库真实路径和角色区分。记录包含主题、讲解、参考文件名、六维反馈与追问。切换资料库不会将旧结果写入新库。

## 题库导入

支持 Markdown、TXT、JSON、DOCX 和带文字层 PDF。选文件后先预览，可修改题干、答案、解析和选项、移除误识别题，再确认入库。支持跳过当前库的重复题。

支持普通编号题、粗体字段、多行解析、代码围栏和以标题作为题干的题目。JSON 的数值零不再丢失。Word/PDF 的布局解析仍需人工预览核对；扫描/图片 PDF 需要先 OCR，当前没有内置 OCR。旧版 DOC 应先另存 DOCX。

## PDF 导出

继续使用内置 Typst 排版，编译改为异步执行。模板、临时源码和本地图片全部复制到独立临时目录，不覆盖或删除用户笔记旁的同名模板。支持相对、本地带空格与括号的图片路径以及并行导出。

缺失或网络图片显示占位说明并返回明确警告，不让整份文件无提示地失败。网络图片需要先保存到本地。输出路径保持用户选择；Markdown、PDF 和 Word 仍为分别可选的格式。

## 验证记录

单元检查：`apps/desktop/companions.test.mjs`、`learning.test.mjs`、`bank-import.test.mjs`。

实际 Electron 集成：`apps/desktop/verify-companion-rooms.mjs`、`verify-bank-export-regression.mjs`、`verify-learning.mjs`。

默认角色集成检查仅用 AI 响应测试替身，实际主进程、预加载、SQLite、界面、导入解析与导出转换器均运行。`--live` 单独使用用户已配置服务对原创测试讲解验证，不把替身记录当作真实 AI 证据。

最终结果以 `output/verification/companion-rooms/`、`output/verification/bank-export/` 及 `产出/learning-studio/verification.json` 中的运行记录为准。安装包不携带这些测试目录、用户账号、会话或凭据。
