# 格致 0.0.6：资料驱动的学习闭环

日期：2026-10-07。基线：原历史提交 `df08355`；本轮在 `codex/material-learning-loop` 分支继续追加，不改写旧提交。

## 当前资料贯穿学习流程

学习工作室有可收起、可调整宽度的资料栏。Markdown / TXT 按标题和有界文本段拆分；DOCX 提取文字；PDF 首次读取前 20 页，可按起止页读取每次最多 40 页。文件上限 32 MB，文本上限 100 万字符。扫描 PDF 仍需 OCR；Word / PDF 的公式对象、图片和阅读顺序可能有损，界面明确提示核对原文。

每个引用包含文件路径、章节、提取文字行号或真实 PDF 页码，以及内容快照。用户可以选择原文中的一段作为当前学习引用。未保存的 Markdown 草稿会标记为草稿快照。内容、位置或草稿状态变化生成新的引用标识，历史记录保留当时使用的内容。

数字空间、学习引导、开放任务、实验、讲解报告和学习证据地图沿用当前引用。主进程校验文件属于当前资料库，跨资料库不能解析或取用另一库的引用。

## 实验与原文的实际关系

按当前章节的明确主题 / 关系式匹配三种已实现的教学模型：二次函数、水平受力与运动、独立事件概率。只提取明确赋值且符合模型范围的参数；未识别参数仍使用教学默认值，界面明确区分。匹配是本地规则，并不表示理解或完整还原任意原题。

不匹配的内容不会默认显示二次函数。可以创建基于原文的反例或迁移任务。内置示例必须由用户显式启用，并标为非当前资料内容。

顺序为参数选择、锁定预测、操作验证、观察解释和控制变量对照。预测之前隐藏函数曲线和概率答案；运动 / 抽样完成后揭晓数值核验。未操作不能保存观察。主进程重新计算运动或抽样数据，不信任前端传来的位移、成功数等结果。

保存内容包括参数、数值预测、依据、自信度、观察解释和运行数据。概率实验保存起始种子，统计可复现；每个新实验使用新种子。文字解释只保存，尚未语义评分。

对照实验保留上一轮参数，只允许改变一个选定参数；后端同样验证恰好一个参数变化、同一资料和已完成的上一轮。函数曲线可以叠加。运动标尺与滑块坐标使用同一比例，两轮对比共用比例。简化力学模型的适用条件仍明确显示。

数值预测答对但未完成实验观察的记录，不再成为已核验的实验通过证据。旧实验没有运行数据时也不会被自动补成已完成。

## 反馈后可直接行动

每个六维反馈项可以定位讲解原话、围绕该项再次讲解，或创建带原文引用的针对性任务。开放任务来自明确模板与当前原文，采用自评，不冒充真题、自动正确判定或独立通过。

再次讲解保留角色、主题和引用。前后分数变化只展示两轮均有可观察证据的维度；未评分维度不补分。AI 请求不会接收旧分数，不因再次尝试自动提高评价。差值是工程记录，尚未经教师评分校准。

讲解报告保存在原角色记录库。证据地图单独展示 AI 报告和可核验作答；AI 分数不改变独立通过统计。资料引用可以展开，并返回原文件或继续探究。Markdown 反馈导出保留引用快照和对比信息，学习记录的三种导出保留实验数据与引用位置。

## 连贯的工作区

学习工作室在切换阅读视图时保留；角色空间与实验在工作室切换功能时保留。角色与练习草稿在当前应用会话内按资料库 / 角色或题目分开保存。专注模式收起辅助引导；资料栏能收起、横向调整宽度，小窗口改为纵向布局。

PDF 页码和缩放、Markdown 阅读滚动、编辑器光标与滚动在当前会话保留。未提交草稿尚不跨应用重启持久化，避免把临时讲解自动写入长期记录；已提交记录仍通过 SQLite 跨重启保存。

已提交的练习可以通过“重新作答”创建新记录。已经查看过反馈的重做保留参考帮助标记，不算作新一次独立通过；实验继续通过新一轮或控制变量对照开始。
