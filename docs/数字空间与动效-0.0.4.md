- 六维反馈：报告展开、雷达图与维度卡片渐显；未展示的维度仍不画分数。
- 连接引导和导入预览：背景淡入、对话框轻微缩放。
- 系统设置为“减少动态效果”时，关闭 CSS 动画与过渡，取消进行中的原生动画。
- 动效挂在现有 DOM 表面，不用更换组件 key 来触发，不因动画重建输入框。

## Markdown 转 PDF 修复

`Ax`、`By`、`AB` 在 LaTeX 中是相邻数学符号。旧转换器保留大写字母串，Typst 将其读成未定义的变量名。

转换器现将这些乘积写为 `A x`、`B y`、`A B`，保留已知算子、希腊字母、命名空间和引号中的英文文字。同时修复相邻关系命令与变量粘连，并保留 `quad` / `qquad` 间距。

此修复没有声称支持全部 LaTeX 环境；不支持的命令仍保留原文与警告。
